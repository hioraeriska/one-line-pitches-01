One sentence to convince a friend who has never coded to let an AI agent build their first app idea on make.fun: "Just describe your app idea in plain words and an AI agent will build it into a real, working app on make.fun — you only pay the winner, so trying costs you nothing."

The program writes the pitch to `entry.txt` (UTF-8, 165 characters, exactly one sentence) — describe the idea in plain words, get back a real working app, and only pay the winner.
